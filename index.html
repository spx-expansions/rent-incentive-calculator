Once linked, this list refreshes automatically every time the page opens — no more manual re-upload when the candidate list changes. Sheet must be set to Anyone with the link can view.
Required columns: Hub Name, Latitude, Longitude, Actual Rent (Php/sqm), Size (sqm). Optional: Region, City (needed to detect Dark Store hubs in VIS/MIN — see the Dark Store toggle in Benchmark Options), Lease Start Date, Lease End Date (lease duration is computed from these the same way the source sheet does — complete months between them, end date inclusive; a raw Lease Duration (months) column is used only if dates aren't given), Direct Lease (Yes/No), Utilization (%), Location Score (%), Go-Live Date, DD Complete (Yes/No), COL Signed (Yes/No), Escalation % (yearly), Actual Renovation Cost, Benchmark Rent Override (Php/sqm) — supply this to skip auto-computation. Benchmark Renovation Cost is auto-computed from a standard rate table by size (₱1,867.45/sqm ≤400sqm, ₱950.91/sqm 401–800sqm, ₱572.02/sqm 801sqm+) — the CSV column overrides this if provided.

The Dark Store buffer adds 100 sqm to a hub's size (used in every calculation below) for any hub in MM, GMA, NCR, or a big VIS/MIN city — Cebu, Mandaue, Lapu-Lapu, Bacolod, Iloilo, Tacloban, Davao, Zamboanga, Cagayan de Oro, General Santos, Butuan, Iligan (needs a City column to check VIS/MIN hubs). Policy Reference
All 7 must pass to qualify (plus go-live inside the program window):
1. Direct leasing (no sublease)
2. Rent ≥15% below benchmark
3. Utilization ≥ MM/NCR 65%, GMA/SOL/NOL 60%, VIS/MIN 40%
4. Total contract savings ≥ ₱1,000,000
5. Lease duration ≥ 24 months
6. Location scorecard ≥ 75%
7. DD complete + COL signed (6-month grace from go-live)
